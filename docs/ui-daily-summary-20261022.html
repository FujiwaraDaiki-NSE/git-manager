改善と加点根拠

#改善分類・点数ユーザー価値と範囲
1ファイル種別の絞り込み機能追加 +5通常ファイル・ディレクトリ・symlink・gitlinkをGitのmode/typeで選択できる。
2ファイル一覧の並べ替え機能追加 +5パス昇順・降順・種別順で取得済み一覧を整理できる。
3表示パスのコピー機能追加 +5調査対象パスをJSON文字列で1行1件コピーし、改行を含むパスも区別できる。
4固定版ファイル一覧のCSV保存機能追加 +5表示対象のpath・kind・mode・objectと固定コミットを表計算や調査記録に保存できる。
5前後ファイルへの連続移動機能追加 +5現在の絞り込みと表示順に沿って本文を順に調べられる。
6本文検索と一致箇所の移動機能追加 +5文字列検索、ハイライト、前後移動、大文字小文字の区別をひとつの検索機能として加点。
7行番号指定で本文へ移動機能追加 +5有効な行番号にフォーカスを移し、初期300行の範囲を超えても該当行を表示する。
8本文の行範囲コピー機能追加 +5開始・終了行を明示し、CRLFを含めた原文をコピーする。無効な範囲は使用不可。
9本文の空白可視化機能追加 +5スペースとタブを識別してインデントを調べる。コピーする原文は保持する。
10本文の長い行の折り返し機能追加 +5長い設定行やドキュメントを横スクロールせずに読める。
11差分ファイルの並べ替え機能追加 +5元順・パス順・変更行数順でレビューする順番を選択できる。
12差分の内容種別フィルター機能追加 +5テキスト変更とバイナリを分けて確認できる。メタデータのみの変更はすべてで保持する。
13表示対象のパッチ保存機能追加 +5フィルター対象だけを元の順序・生パッチを保持して書き出す。
14差分のレビュー済み管理機能追加 +5ファイル単位の印、進捗、確認済み非表示を一つの機能として加点。パッチ変更時にリセットする。
