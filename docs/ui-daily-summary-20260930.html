表示の改善

  • コミットのファイル数・既知の増減行数・バイナリ数を集計カードで表示。
  • 折りたたまれた差分でもファイル別の増減量・バイナリ状態がわかる表示。
  • 作業ディレクトリ → ステージ → コミットの図で、状態とGitコマンドの関係を表示。

各2点、計6点。機能追加65点と合わせて71点分の改善。30点開始の加点方式では101点で、100点の目標に到達しました。この点数はユーザー指定の改善量を表し、客観的な品質保証ではありません。

状態とデータの扱い

バイナリの行数や未取得値は0と同一視しません。検索・コピー・書き出しは取得済みの表示データを使用します。TSVは数式として解釈される文字列をエスケープし、名前変更前のパスも保持します。Gitコマンドはコピーのみで、自動実行しません。
