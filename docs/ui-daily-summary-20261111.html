検証

フロントエンド362件、バックエンド302件のテストとNext.jsの本番ビルドが通過。既定のgitdash-composeで再ビルド・再起動し、バックエンドのhealthyとHTTPのヘルス応答を確認。

  • Chromeで、名前変更、バイナリ、追加、削除を含む59件の実Git差分を取得。25・50・100件のページ表示、パス検索範囲、除外、変更行数、追加・削除、計測不能の条件を操作した。
  • all ディレクトリ選択時に全59件を表示する不具合を変更前に再現し、変更後は該当する55件を表示した。ディレクトリ集計の src から3件に絞り込めた。
  • ダウンロードしたJSONはAPI応答と一致した。別ページで選んだ2件だけがTSVに含まれた。Markdownのハッシュ、切り詰め情報、集計、再現コマンドを確認した。
  • 固定URLは比較条件を反映し、実行ボタンを押した後に取得した。共通祖先からの差分を逆方向に取得し、直前成功結果からファイル数が58件減少する表示と、取得失敗後の成功結果保持を確認した。
  • デスクトップと幅390pxのChromeで確認。幅390pxでもページ全体の横方向のはみ出しはなく、除外条件が動作した。
