# ブランチ間のつながり: 完了条件

- ブランチ行を保ち、行の見出し同士を実際の矢印で結ぶ。
- マージ矢印はPRの元から先へ向く。分岐の推定は基準ブランチから比較対象へ向き、点線と明示ラベルで確定事実から区別する。
- PR番号・マージコミット、推定の共通祖先を根拠として表示する。作成イベントの独自保存をしない。
- 同名の別リポジトリ、複数候補、欠落参照を誤接続しない。判定できない理由を示す。
- 検索・並び替え・完了履歴折り畳み・行展開・リサイズ後も、表示中の正しい行へ接続する。
- 隠れている相手は関係として残し、相手を表示する操作を提供する。
- リモートとローカルのupstreamによる集約、コミット選択・履歴ページング、前回のUI改善を保持する。
- design_db PR #168のdrawing-zones → integrationをAPIとGUIで確認する。
- テスト、本番ビルド、Compose反映、GUIの目視・操作、P1レビューを完了してからpush/PR。
