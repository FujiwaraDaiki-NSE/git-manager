UI改善の統合とGitHub認証

ローカルmainに残っていたe785f0fのUI改善を、PR #34のブランチ一覧と統合した。検索・並び替え、差分検索、パッチコピー、Gitガイド、JSON/TSV保存を復元する。

ホストのghはログイン済みだったが、起動プロセスにGH_TOKENが存在しなかった。ホストのgitdash-composeで毎回gh auth tokenを実行してexportすることで、既存のCompose環境変数受け渡しを有効にした。トークンをソースや設定ファイルへ保存しない。

ホスト側起動スクリプトの認証処理:

GH_TOKEN="$(gh auth token --hostname github.com)"
export GH_TOKEN
