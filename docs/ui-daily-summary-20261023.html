Gitと定期設定

保存されていた実行時刻が毎日2時だったため、既存automationを毎日8時に修正してACTIVEを維持。ホストのタイムゾーンはAsia/Tokyo。モデル・推論設定・プロンプト・対象プロジェクトは保持。定期設定変更はUI採点に含めない。
