ブランチ単位の表示とホスト認証

現在のブランチを起点に履歴を確認する表示へ変更する。履歴全体を一つずつ過去のブランチへ割り当てる方式をやめ、Gitの参照と追跡先、GitHubのPRから表示を構成する。開発イベントの独自保存は行わない。

取り込みと分岐

PRが示す取り込み元から取り込み先への関係を表示する。共通祖先から当時のブランチ名や作成元を断定しない。名前が確認できないコミット経路は、架空のブランチ行にしない。Gitのコミットや既存の詳細画面を削除する変更ではない。

GitHub認証

Composeはホスト起動プロセスの GH_TOKEN と GITHUB_TOKEN をそのままbackendへ引き継ぐ。優先順位はghが決める。トークンをブラウザ・ログ・リポジトリへ出さず、保存済みgh認証の自動取得もしない。環境変数がない場合、PR取得不可とGitから確認できる状態を区別する。

通常の起動・再作成にも同じ環境変数が必要。ホストの環境変数を更新した場合は、コンテナの再作成で反映する。
