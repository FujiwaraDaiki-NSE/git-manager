agentが「何を判断してほしいか」を質問・選択肢・参照URLとして報告できるようにし、ホームカードとタイムライン・詳細に表示しました。ホームの「次に確認」はagentが入力待ちのブランチを優先します。Git状態の取得失敗を「変更なし」と数えていた問題などを修正し、詳細APIの転送量とホームの初回表示を改善しました。
