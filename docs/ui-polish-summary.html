何が変わったか

差分を読みやすく

  • 追加・削除の色分けと変更前後の行番号。
  • ファイル単位の展開、折り返し、ファイル検索。
  • 300行ずつ追加表示。全行表示・差分全体コピーも可能。
  • 日本語名と名前変更前後のパスを正しく表示。

探した状態を維持

  • 作業一覧とアクティビティの検索・フィルター・並び順をURLに保存。
  • 再読み込み、戻る・進む、URLコピーで表示条件を維持。
  • カードの変更あり・未pushなどから、対応する一覧へ移動。
  • 同名プロジェクトは作業パスで見分けられるように。

Git状態を正確に

  • 変更ファイルをステージ済み・未ステージ・未追跡・競合で検索。
  • 初回コミット前のブランチをdetached HEADと区別。
  • 開いているGit詳細もブランチ追加に自動追従。
  • 既定ブランチとの差と追跡先との差を別々に表示し、意味を説明。

更新と復帰を安定化

  • 深いrefsの変更と、状態取得直後のpushも取りこぼさずに更新。
  • 更新失敗時は前回の内容であることを明示し、再取得を用意。
  • SSEの早期切断時に購読を解放。再接続時は走査・fetch状態も送信。
  • 画面幅変更後や入れ子の詳細を閉じたあと、元の操作へフォーカスを戻す。
