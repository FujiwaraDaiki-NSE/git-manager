ブランチごとのコミット表示を復元

元の画面は、左にブランチ名、右に横方向の時間軸、各行にコミットの点、行をまたぐ分岐・合流線があるタイムラインだった。カード一覧に置き換えたPR #34と、カード間の矢印を追加したPR #36ではこの表示を保持できていなかったため、1f20d14の表示を基に戻す。

表示とデータ取得の分離

表示する行は、リモート追跡参照とローカルupstreamから組み立てる。各行のコミットはその先端から親を再帰的にたどって取得する。同じコミットを複数のブランチ行へ表示できるため、当時のブランチ名への唯一の所属を推定しない。

分岐推定は共通祖先、PR取り込みは確認済みの元コミットとマージコミットへ結ぶ。接続に必要なコミットは最初の200件から独立して取得し、日時不明を先端の日時で代用しない。履歴の追加取得はブランチごとに行う。

保持する機能

PR #35の検索・差分確認・Gitガイドと、ホストgh認証を維持する。コミット選択では同じ行の正確な先端対応からworktreeを特定し、複数候補を勝手に選択しない。
