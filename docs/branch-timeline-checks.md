# 元のブランチ・コミット表示の復元条件

参照実装: 1f20d14 の frontend/app/project-control.tsx の FlowMap、FlowEventButton、FlowEventPopover と project-flow.mjs。

- 左にブランチ名、右に横方向の時間軸、各行にコミットの点を並べる元のレイアウトを復元する。
- カード一覧とカード端の矢印は採用しない。
- 現在のbranch_rowsを行の正本にし、各ブランチ先端から親をたどる履歴を使う。同じコミットの複数行への表示を許容する。
- 不明な過去の所属ブランチを合成しない。upstreamによるローカル・リモート集約を保持する。
- コミット間は親子関係、ブランチ間はPRと共通祖先の証拠で結ぶ。分岐推定とPRマージを区別する。
- 時間軸・範囲切替・点のプレビューと詳細・ブランチ移動・横スクロール・過去観測時点の操作を保持する。
- 200件で切れた履歴はブランチ単位で追加取得でき、全ブランチの全履歴を無制限に取得しない。
- 関係の日時は現在の先端日時で代用しない。初回履歴ページの外にある根拠コミットも個別に取得し、欠落は明示する。
- GUIで見た目が元の横型タイムラインであること、コミット選択、分岐・マージの向き、狭幅を確認する。
