## 正確性

- worktree所属は `project.worktrees`、作業詳細へのリンクは一意の完全一致パスのみ。
- worktreeの状態未取得はmain/detachedと独立。dirty/conflictの一方が未取得でも不明表示を保持。
- PRは取得済みブランチに関連するマージ済み記録のみ。GitHub未取得と確定した0件を区別。
- 履歴検索・ソート・保存は取得済みコミットのみ。未取得履歴まで検索したとは表示しない。
- 親情報が未取得のコミットを通常コミットと推定しない。
- 履歴ページ取得をプロジェクト・行・HEAD・初期ハッシュ集合に関連付け、切替時に中断して古い応答を除外。
- CSV/TSVは表計算ソフトの数式開始文字を無効化。コピーするcdコマンドはPOSIXシェル引用。
