グラフ画面のUI/UX整理

2026年9月14日。情報設計・視覚設計・操作性を3人のエージェントが独立して検討し、既存機能を維持したまま画面の優先順位を見直しました。

変更と理由

  • 名称と既定ブランチを常設し、概要・集計を開閉できる領域へ集約。グラフまでの情報量を減らしました。
  • 操作説明、表示範囲、補助操作、グラフの順に配置。凡例はグラフ直後で確認できます。
  • ブランチ名の列を広げ、行高を88pxに統一。既定ブランチ、選択行、詳細の関係を色と選択状態で示します。
  • 点と線は同じ行高変数で配置。点の選択状態を支援技術にも伝えます。
  • タブの矢印キー・Home/End操作とtabpanelの対応を整理。小画面ではタブを2列に並べ、再走査も利用できます。
  • 一覧画面と周辺タブの見出し・補足文を簡潔に揃えました。

影響範囲

Next.jsの表示とナビゲーションのみ。API契約、保存状態、Git操作、ブランチ判定、履歴取得は変更していません。概要・集計、完了ブランチ、履歴時点、Git詳細は引き続き利用できます。

確認

Production build、既存29テスト、reviewerのP1確認、実データでのブランチ選択・詳細表示・表示範囲・過去表示と最新復帰・390px幅・キーボードタブ移動を確認。実機のスクリーンリーダー確認は行っていません。
