# 合流矢印の重なり改善

- 原因: 近接時刻の合流線を同じx位置への斜線として描き、stroke幅に比例する大きなmarkerを終点に配置していた。
- 方針: 合流時刻の両端は維持し、重なるレーン区間ごとに16px間隔の経路を割り当てる。方向は線の途中の小さな矢印で示す。
- 選択: 選択ブランチに関係する線を強調し、それ以外も薄く残す。
- 検証: 同時刻30件・両端時刻・上下方向・入力順の安定性・非重複区間の列再利用をテスト。GUIで多数ブランチ、選択時、モバイルを確認。
- mainからworktreeで実施。reviewer確認後、PRをmainへマージしComposeで反映する。
