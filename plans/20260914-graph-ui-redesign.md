# グラフ画面のUI/UX整理

開始ブランチ: main。作業: codex/graph-ui-redesign のworktree。

3人のエージェントが情報設計、視覚設計、操作性を独立調査した。共通の原因は、グラフ前の情報が多く、操作と補足情報の優先順位が不明確なこと。

## 実施内容
- 名称と既定ブランチを常設し、説明・識別情報・最新コミット・集計を概要の開閉領域にまとめる。
- タブの重複する英語表記を整理。キーボード操作とtabpanelの対応を設定。
- グラフ見出し、短い操作説明、範囲と補助操作、グラフの順に配置。
- 凡例はグラフの直後。履歴操作と過去表示の注意、取得不能の理由は維持。
- 固定ラベルを広げ、88pxの行高をSVG計算と一致させる。既定・選択の表示を改善。
- 点の選択状態を支援技術に公開。小画面でも再走査を維持。

## 完了条件
既存機能・API契約・URL復元を維持。ビルドと既存テスト、実データでGUI操作を確認。reviewerのP1があれば修正。PRをmainへマージしてComposeで起動を確認。
