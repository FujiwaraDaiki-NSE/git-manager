# graph-api 実装計画

## 目的

既知の Git リポジトリに対するコミットグラフ、コミット詳細、ブランチ一覧の
読み取り専用 API を backend に追加する。

## 方針

- `STATE` に登録済みのホストパスだけを受け付ける。
- Git 実行はリポジトリ単位の `_repo_lock()` と既存の `pool` を経由する。
- パース処理は `app/detail.py` に分離し、`main.py` は HTTP と実行制御に保つ。
- `frontend/` は変更しない。

## 検証

- `/tmp/gd` の fixture に対して3 APIを実リクエストする。
- `graph.py` のレーンを `git log --all --date-order --oneline --graph` と照合する。
- 未登録パスと不正な hash が拒否されることを確認する。
- 実装後に reviewer サブエージェントで安全性と回帰を確認する。
